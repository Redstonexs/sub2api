# tools/tests

`upstream_sync_test.sh` is a pure-bash, network-free fixture harness for `tools/upstream_sync.sh` (the upstream-sync engine, TDD: the harness is written first and currently fails RED). For each scenario (S1 clean merge, S2 whitelist auto-resolution, S3 necessary conflict, S4 no-op, S5 fork-file regression, S6a/S6b UD/DU deletions, S8 annotated tag) it builds a fresh, throwaway fixture pair under `mktemp -d` — a local "upstream" git repo with tagged releases plus a local-path "fork" clone — invokes the engine inside the fork via the frozen env contract (`UPSTREAM_URL`, `UPSTREAM_TAG`, `BASE_BRANCH`, `STATE_FILE`), and reports TAP-style `ok`/`not ok` lines with a final `PASSED: x/y` summary, exiting non-zero if any scenario fails; temp dirs are always removed by an `EXIT` trap. All git remotes are plain filesystem paths, so the suite uses zero network access. Run it with `bash tools/tests/upstream_sync_test.sh` from anywhere.
